Underwear base body for the player (so outfits can be fitted later) — see [[projectzed-shooter]].

- Build scripts live in `My project/Blender/Scripts` (moved out of temp scratchpads on 2026-10-20): `make_base.py` (MPFB male body + Mixamo rig fitted to Ch17's skeleton, cut at neck/wrists so Ch17's head and hands stay, boxer-brief underwear from the hip band, skin colour sampled from Ch17's texture), `fit_sculpt.py` (step 3b), `render_views.py`, `render_34.py`. Run headless: `blender.exe -b --python-exit-code 1 --python make_base.py` (needs the MPFB extension, so no `--factory-startup`). Blender 5.2 at `C:/Program Files/Blender Foundation/Blender 5.2/`. Blender can't open scripts from the long temp scratchpad paths (MAX_PATH), so keep scripts in the project.
- Input `Blender/Player/Ch17_Player.blend`; outputs: `Ch17_Base.blend` (old MPFB-only), `Ch17_Base_v2.blend` (MPFB with neck/wrist/skin fixes), `Ch17_Base_v3.blend` (current: shaped by the sculpt). Renders in `Blender/Player/renders`.
- BlendSwap asset 21626 (Human Male Base Mesh, CC0, by nashnir) downloaded 2026-10-20 to `Blender/Sources/BlendSwap_21626_HumanMaleBaseMesh`. It's a 650k-tri sculpt with no UVs/weights, so it's used only as a shape target: MPFB body is projected onto it (topology, UVs, weights stay MPFB's). Shoulders/armpits are excluded and smoothed (sculpt creases when its A-pose arms are raised); front of crotch is kept MPFB's.
- Neck cut now uses Ch17_Body's actual neck boundary loop (tilted ~23°), which removed MPFB's leftover back-of-neck sheet and scalp.
- Open issues as of 2026-10-20: crumpled fold where body meets Ch17's neck (front collar and back), stair-stepped underwear waistband edge, slightly wavy arms, Ch17 hair cap shows a bald band (hair was made for a helmet). Not yet exported to Unity.

Game body from the sculpt itself (2026-10-20, user asked to use the BlendSwap mesh as the base): `Blender/Scripts/make_game_body.py` (run after make_base.py) → `Ch17_Base_v4.blend` + `Assets/Characters/BaseBody/Ch17_BaseBody.fbx`. Voxel remesh 0.02 → QuadriFlow (finer voxels get rejected) → weld halves → shrinkwrap to sculpt; crotch snapped to MPFB; weights from the MPFB body; ~11.3k verts / 22.5k tris; pose test (`pose_test.py`) deforms fine. Applied in Unity 2026-10-20 via `Assets/Editor/BaseBodyBuilder.cs` (Tools > Characters > Apply Base Body to Player / Restore Player Outfit; headless `-executeMethod BaseBodyBuilder.ApplyFromCommandLine`). It moves the FBX meshes into the original Ch17_Body mesh space (scale 0.01, checked to 0.00 mm) and reuses bindposes by bone name from all original Ch17 SMRs, saving `Assets/Characters/BaseBody/Base_Body.asset`, `Base_Underwear.asset`, `Base_Skin.mat`, `Base_Underwear.mat`; adds SMRs under Player/Body and hides the outfit on the player only (NPCs keep it). Scene saved. Headless snapshots with clips via a PlayableGraph showed correct skinning; Play mode in the editor not yet checked. After re-running Blender scripts, re-run the menu item. Humanoid clips don't pose via AnimationClip.SampleAnimation in batch mode — use a PlayableGraph.
