# Animation references (DayZ / Arma)

Reference footage for cleaning up ProjectZed's character animations. Gathered from YouTube searches
(2026-10-20); picked by title/channel/date, so skim before relying on one.

DayZ rebuilt its animation system in 0.63 (2018) — that's the look to aim for. Videos from 0.48–0.50
(2014–15) show the old Arma-2-style movement and are only useful for contrast.
